# КНН пары

Пары своей группы из PDF-расписания и вход на ВКС-пары преподавателей в один тап.

## Android

**[⇩ Скачать KNN-pary.apk](https://github.com/poddon/knn-pary/releases/download/latest/KNN-pary.apk)**

1. Скачай APK и открой его. Разреши установку из этого источника.
2. Введи своё ФИО и выбери группу.
3. Каждый день делись PDF с расписанием из MAX в «КНН пары».

Приложение само заходит на пары (только слушать) и выходит после их окончания. Для автооткрытия разреши «Поверх других приложений» (кнопка на вкладке «Расписание»).

## Windows (ноутбук)

**[⇩ Скачать KNN-pary.exe](https://github.com/poddon/knn-pary/releases/download/latest/KNN-pary.exe)**

1. Запусти файл. Если Windows скажет «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае».
2. Приложение установится само, добавит значок на рабочий стол и будет запускаться вместе с Windows.
3. Разреши «таймеры пробуждения» (спросит при первом запуске).
4. Введи ФИО, выбери группу и загрузи PDF с расписанием.

Перед каждой парой ноутбук сам проснётся из сна, зайдёт на пару с твоим ФИО (только слушать) и выйдет после неё. Работает и при заблокированном экране. Держи ноутбук на зарядке с открытой крышкой.

## iPhone и браузер

**[poddon.github.io/knn-pary](https://poddon.github.io/knn-pary/)**

Открой в Safari → «Поделиться» → «На экран „Домой“». Кнопка «Войти» копирует ФИО и открывает конференцию.

Уведомления о парах: после загрузки PDF нажми «Напоминания о парах в Календарь» → «Добавить все». За 3 минуты до каждой пары iPhone пришлёт уведомление, в событии будет ссылка для входа.

## Устройство

- `app/` — Android-приложение (Java, без AndroidX). Разбор расписания: `ScheduleParser.java`.
- `windows/` — приложение для Windows (C#, WinForms + WebView2), собирается GitHub Actions в один exe.
- `app/src/main/assets/teachers.tsv` — преподаватели и ссылки на комнаты ВКС.
- Ветка `gh-pages` — веб-версия.
- APK собирается GitHub Actions при каждом пуше в `main`.
